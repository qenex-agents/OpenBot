# Security Policy

## Supported versions

QENEX maintains security review for the active default branch and the latest released version of this repository. Older branches are supported only when they are explicitly used in production by QENEX.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately to the QENEX maintainers through the approved internal security channel or a private repository advisory.

Please include:

- Repository and affected version or commit
- Impacted component, command, API, or deployment surface
- Reproduction steps or proof-of-concept details
- Expected impact and suggested mitigation, if known

## Response expectations

Maintainers should acknowledge receipt, triage severity, create a private remediation task, and publish a fix or mitigation before public disclosure.

## Scope

This policy covers this repository only. It does not authorize testing against QENEX production systems or third-party infrastructure without explicit approval.
